This module makes adjustments to the analytic account views.

Currently it turns the reference, the customer, the plan, the debit, the
credit and the balance into optional columns of the analytic account
list, hidden by default, leaving the name of the account as what the
list is read by. Whoever wants one of them back adds it from the column
menu of the list, and that choice is remembered for the next time.
