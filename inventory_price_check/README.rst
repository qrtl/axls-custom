This module checks for discrepancies between the receipt price and the
standard price at the time of validation.

.. contents::
   :local:

Configuration
=============

Go to the product, and under the Inventory tab, set up the 'Price
Discrepancy Threshold Type' and 'Price Discrepancy Threshold Value'. For
the global setup, go to Inventory > Settings and configure the 'Price
Discrepancy Threshold Type' and 'Price Discrepancy Threshold Value'.
This global value will be used if no specific value is set for the
product. Assign the internal user to the Inventory Price Check Bypass
group to make the 'Allow Price Inconsistency' checkbox visible.

Usage
=====

A warning message will be displayed during validation if the difference
between the receipt price and the standard price exceeds the threshold.

Selecting 'Allow Price Inconsistency' allows users to bypass this error,
and it is only visible to members of the Inventory Price Check Bypass
group.
